# TimeCompass · 目标时间管理

按目标记录时间、拆解任务、追踪习惯的极简时间管理工具。**单个 HTML 文件，双击即用，无需安装、无需服务器、无需账号。**

线上版本：<https://time-compass.netlify.app>

## 它解决什么问题

大多数时间记录工具只告诉你"时间花在哪些事上"，但不回答更重要的问题：**这些时间有没有花在真正重要的目标上。**

TimeCompass 的做法是先给每个目标设一个「计划权重」（你希望投入的精力占比），再把实际投入和它对比 —— 偏差一眼可见。

## 功能

**今日**

- 计时器（开始 / 停止自动记录）或手动补录时长
- 每日习惯打卡，连续天数与 21 天热力条
- 四个关键数字：今日投入、习惯打卡、P1 任务占比、高优先级目标占比

**日历**

- 月历视图，每天显示按目标着色的时间分布条与习惯打卡点
- 点任意一天查看明细，可回头补打卡

**目标**

- 目标设优先级与计划权重
- 每个目标拆解成任务，带预估工时、截止日期、完成状态
- 完成率、累计投入、逾期数一览

**分析**

- 计划权重 vs 实际投入的偏差对比
- 任务完成进度表（完成 / 进行中 / 未开始 / 逾期）
- 每日投入堆叠图、优先级分布
- 自动诊断：哪个目标投入不足、还差多少小时、哪些低优先级事项吃掉了时间、哪些任务按当前进度赶不上截止日

## 使用

下载 `index.html`，双击用浏览器打开即可。

或者部署成网页版（推荐，这样手机也能用）：

1. 打开 <https://app.netlify.com/drop>
2. 把包含 `index.html` 的文件夹拖进去
3. 得到一个网址，手机浏览器打开后可「添加到主屏幕」

也可以用 GitHub Pages：仓库 Settings → Pages → Source 选 `main` 分支根目录，几分钟后即可通过 `https://<用户名>.github.io/time-compass/` 访问。

## 数据

- 全部数据存在浏览器的 localStorage 里，**不上传任何服务器**
- 每台设备、每个浏览器各存一份，互不同步
- 右上角「导出备份」可下载 JSON，「导入」可恢复；跨设备迁移也用这个
- 清除浏览器数据会丢失记录，建议定期导出备份

## 技术

无框架、无构建步骤、无依赖。单个 HTML 文件，约 1900 行，包含全部 HTML / CSS / JavaScript。
